## О проекте

Я создал этот сайт для своего младшего брата, чтобы помочь ему разобраться в теме **«Тропы в литературе»**. Вместо длинного и скучного конспекта получилась небольшая интерактивная презентация: с наглядными примерами, шутками, карточками и проверкой знаний.

Главная задача проекта — объяснить материал так, чтобы его было легко понять, запомнить и повторить перед уроком.

## Что изучаем

На сайте собраны шесть основных тропов:

| № | Троп | Что делает |
|---:|---|---|
| 01 | **Эпитет** | Образно описывает предмет или явление |
| 02 | **Сравнение** | Сопоставляет один предмет с другим |
| 03 | **Метафора** | Переносит значение по сходству — создаёт скрытое сравнение |
| 04 | **Олицетворение** | Приписывает неживому человеческие качества и действия |
| 05 | **Гипербола** | Намеренно преувеличивает |
| 06 | **Литота** | Намеренно преуменьшает |

## Возможности сайта

- **Наглядное объяснение.** Сравнение обычной фразы с художественной показывает, как меняется речь.
- **Интерактивные карточки.** Нажми на название тропа, чтобы открыть определение и пример.
- **Разбор примеров.** Короткие объяснения помогают понять, почему конкретное выражение относится к выбранному тропу.
- **Мини-тест.** Пять вопросов, проверка ответов и итоговый результат.
- **Юмор и ироничные подписи.** Материал подаётся легко, но определения и объяснения остаются учебными.
- **Адаптация под устройства.** Сайт автоматически подстраивается под компьютер, планшет и смартфон.
- **Удобная навигация.** Меню, индикатор прокрутки и кнопка возврата наверх помогают ориентироваться по странице.

## Дизайн и идея

Визуальный стиль построен на контрасте тёмного и светлого фона с красными акцентами. Крупная типографика, свободное пространство и журнальная подача делают сайт похожим на современный цифровой лонгрид, а не на стандартную школьную презентацию.

**Цветовая идея:**

- `#111110` — почти чёрный;
- `#F2EFE8` — тёплый светлый фон;
- `#F04D3D` — красный акцент.

Интерфейс рассчитан и на мышь, и на сенсорное управление. На небольших экранах меню, карточки, тест и всплывающие окна перестраиваются для удобного использования пальцем.

## Технологии

| Технология | Для чего используется |
|---|---|
| **HTML5** | Структура и содержание страницы |
| **CSS3** | Визуальный стиль, адаптивная вёрстка и анимации |
| **JavaScript** | Карточки, примеры, меню, модальные окна и тест |

Проект сделан на чистых HTML, CSS и JavaScript — **без React, сторонних UI-библиотек, npm и сборщика**. Основная версия сайта находится в одном файле `index.html`.

## Как запустить

### На компьютере

1. Скачай или клонируй репозиторий.
2. Открой папку проекта.
3. Запусти `index.html` в любом современном браузере.

```bash
git clone <URL-репозитория>
cd tropy-literature-site
```

После этого открой файл `index.html`.

### На телефоне

Сайт адаптивный — отдельную мобильную версию скачивать не нужно. Можно открыть опубликованную ссылку на телефоне. При локальном запуске открой `index.html` через браузер или используй статический веб-сервер.

> Для загрузки Manrope и Playfair Display требуется интернет. Если сети нет, сайт использует запасные системные шрифты; основные материалы и интерактивные функции остаются внутри `index.html`.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория `index.html` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери публикацию из ветки `main` и папки `/ (root)`.
5. Сохрани настройки. После публикации GitHub покажет ссылку на сайт в разделе Pages.
